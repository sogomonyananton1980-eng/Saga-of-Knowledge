# Saga of Knowledge

Учебный веб-проект для изучения программирования на C++.

## Текущая версия
Адаптивная главная страница в тёмной стилистике с CSS 3D-композицией, интерактивной реакцией на курсор и карточками учебных разделов.

## Запуск
Откройте `index.html` в браузере или запустите проект через расширение Live Server в Visual Studio Code.

## Структура
- `index.html` — разметка главной страницы.
- `style.css` — оформление, адаптивность и CSS-анимации.
- `script.js` — интерактивность и реакции на курсор.

Пока учебные разделы представлены демонстрационными блоками. Следующие этапы — реализация лекций, квестов, сохранения прогресса, ассистента Saga и онлайн-компилятора.
